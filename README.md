## 📌 Project Overview

This project focuses on implementing a Security Operations Center (SOC) using Wazuh SIEM to monitor, detect, and analyze security events from endpoint systems in real time.

It simulates real-world threat detection scenarios such as unauthorized access attempts, malware detection, brute-force attacks, and system integrity monitoring.

---

## 🎯 Objectives

- Deploy and configure Wazuh SIEM for centralized security monitoring
- Integrate endpoint systems using Wazuh agents
- Detect and analyze security threats in real time
- Visualize security alerts using Wazuh Dashboard (Kibana/OpenSearch)
- Understand SOC workflows and incident detection lifecycle

---

## 🛠️ Tools & Technologies Used

- Wazuh SIEM
- Wazuh Manager
- Wazuh Agent
- Elasticsearch / OpenSearch
- Wazuh Dashboard
- Linux / Windows Endpoint Systems

---

## 🏗️ SOC Architecture

Endpoint System → Wazuh Agent → Wazuh Manager → Elasticsearch/OpenSearch → Wazuh Dashboard → Security Alerts & Monitoring

---

## 🔐 Security Use Cases Monitored

- Failed login attempts
- Brute-force attacks
- Command execution detection
- Malware detection (EICAR test file)
- Network scanning activities

---

## 📊 Key Features

- Real-time log analysis
- Centralized security monitoring
- Alert generation based on rule severity
- Dashboard visualization of security events
- Agent-based endpoint monitoring

---

## 📈 Outcome

This project successfully demonstrates how a SOC environment works using Wazuh SIEM, including real-time threat detection, log analysis, and security visualization.

It helps in understanding practical cybersecurity monitoring and SOC analyst workflows.
